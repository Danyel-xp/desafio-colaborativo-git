## Sobre o projeto
 Este projeto foi desenvolvido com o objetivo de praticar Git, GitHub e desenvolvimento colaborativo, utilizando Python para criar uma calculadora simples executada pelo terminal.

 Foram praticados conceitos como:

- Criação e utilização de branches
- Commits
- Push e Pull
- Merge
- Resolução de conflitos
- Trabalho colaborativo
- Organização de branches por funcionalidades
- Uso do GitHub para compartilhamento do projeto

## Características da aplicação

![alt text](image-3.png)

É uma calculadora executada diretamente pelo terminal.

O usuário pode escolher entre diferentes operações matemáticas, além de uma opção para sair do programa:

- Soma
- Subtração
- Multiplicação
- Divisão
- Sair


## Dependências
instale as dependências necessárias:
- [Python](https://www.python.org/downloads/)
- [Git](https://git-scm.com/install/)

## Requisitos para execução
 clone o repositório:

 ```
 git clone https://github.com/Danyel-xp/desafio-colaborativo-git.git
 ```
Entre no diretório `desafio-colaborativo-git/` e execute:

```
python calculadora.py
```
